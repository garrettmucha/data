Privacy Policy

Last updated: June 22, 2025

Data Collection

Lightning Runner collects minimal data necessary to provide CI/CD services:

  • GitHub repository names and workflow configurations
  • Workflow execution logs (retained for 7 days)
  • Usage metrics (build minutes, job counts)

Data Usage

We use collected data solely to:

  • Execute your GitHub Actions workflows
  • Monitor service performance
  • Provide usage statistics

Data Security

All workflow data is processed in ephemeral containers that are destroyed after job completion. We do not store source code or secrets.
